# 播放偏好与片头片尾

## 设置入口与保存范围

在「设置 → 播放」(`/settings?section=playback`) 配置自动播放下一集、自动跳过片头片尾和偏好语言。所有已登录角色都可以查看；保存需要 `PlaybackWrite` 权限，默认由 Admin 和 Member 拥有。偏好保存在服务器上的当前档案中，同一档案在其他设备登录后也会读取这些设置；切换档案后使用对应档案的偏好。

播放器页面不再提供独立的偏好卡片或自动跳过开关。播放器控制栏仍可临时切换、关闭字幕，包括在全屏中操作；这些操作只影响本次播放，不写入档案偏好，也不改变下一部视频的默认语言。

自动播放下一集在本集结束后打开并播放下一集已下载内容，仍受浏览器自动播放策略限制。自动跳过默认关闭，启用后的行为见下文。

## 偏好语言

一个偏好语言同时用于默认字幕和音轨。选择「自动」时，播放时跟随当前界面语言。语言匹配会归一化地区后缀，以及媒体中常见的 `chi` / `zho`、`jpn`、`eng` 标识。

- 字幕选择覆盖外置字幕和稍后发现的内嵌字幕；用户已手动选择字幕后，不会因新的字幕被发现而覆盖本次选择。
- MKV 的可播放性探测和 Mediabunny 实际播放使用相同的音轨选择方式，优先选取匹配语言的音轨。
- 需要服务端 HLS 回退时，字幕和音轨请求传递相同的有效偏好语言。
- 直接使用浏览器播放时，在浏览器提供 `audioTracks` 的能力范围内选择匹配音轨。没有匹配音轨时保留默认音频；没有暴露音轨切换能力的浏览器无法通过此路径强制切换。

偏好只决定已有且可用轨道的初始选择，不会生成缺失字幕或配音。内嵌字幕仍受现有解析格式限制，浏览器 MKV 路径不支持的位图字幕不会因此变得可用。

### 历史数据兼容

沿用现有播放偏好 API 与数据字段，不新增数据库字段：保存明确语言时，将同一值写入 `SubtitleLanguage` 和 `AudioLanguage`；保存「自动」时，两者写入 `null`。保存同时清空旧的 `SubtitleTrackLabel` 和 `AudioTrackLabel`。

读取历史偏好时，优先采用有效且非 `off` 的字幕语言，其次采用音频语言；两者都未设置时跟随界面语言。旧的具体轨道标签不再参与自动选择，也不再在设置页提供编辑入口。历史数据曾使用的字幕 `off` 不再作为全局关闭字幕的设置；需要关闭当前视频字幕时，使用播放器控制栏。

## 自动跳过的现有能力

自动跳过使用已标注的片头、片尾区间，不包含新的音视频识别引擎。Admin 和 Member 仍可在播放器编辑共享时间轴。单集标注优先；整季模板按番剧、季、字幕组隔离，必须对当前媒体版本显式接受后才生效。没有可用标注时，不会凭固定时长猜测并跳过内容。

播放器进入有效区间后跳到区间结束点，因此正确标注的片尾区间可以保留之后的剧情。既有文件版本校验和进度保护继续生效，不会仅因跳过片尾而标记整集已看完。编辑时间轴需要 `ContentWrite`，与保存个人播放偏好的权限分开。时间轴版本、整季模板和进度规则详见 [订阅、下载与观看](library-workflows.md#个人追番与章节)。

## 其他播放器如何识别

以下资料于 2026-09-28 查阅。自动识别通常发生在媒体入库后或后台任务中，播放器根据生成的开始、结束时间执行跳过。

| 实现 | 方法 | 适用条件与限制 |
| --- | --- | --- |
| Plex 片头 | 在同季多集的开头寻找重复音频，例如主题曲，可在入库时或定时任务中分析。 | 依赖重复内容；官方说明忽略不足 20 秒的片头，以及结束位置超过全片一半的片头。[官方说明](https://support.plex.tv/articles/skip-content/) |
| Plex 片尾 | 机器学习结合文字检测、黑帧等信号确定片尾开始与结束，支持跳至片尾中间或之后的彩蛋。 | 官方承认仍可能误识别，公开介绍没有提供可直接复用的完整算法。[官方介绍](https://www.plex.tv/en-gb/blog/let-the-next-episode-roll/) |
| Jellyfin 社区插件 Intro Skipper | 使用文件内已命名章节、Chromaprint 跨集音频指纹、黑帧和静音检测；音频指纹可以缓存复用。 | 章节最快但依赖正确命名；音频指纹需要分析多个文件，黑帧与静音本身不能说明片段的语义。[项目文档](https://github.com/intro-skipper/intro-skipper/wiki#detection-types) |
| mpv 社区脚本 | `chapterskip` 按章节标题跳过；`mpv-auto-chapters` 对缺少章节的动漫解析片名和集数，通过 AniSkip 查询时间段，再交给章节跳过脚本使用。 | 前者依赖章节，后者依赖作品和集数匹配及外部数据覆盖，并不是本地音视频分析。[chapterskip](https://github.com/po5/chapterskip)、[mpv-auto-chapters](https://github.com/po5/mpv-auto-chapters) |

## 后续实现建议

优先读取文件内章节：在服务器现有 ffprobe 探测基础上增加章节信息，识别明确的 `OP` / `Opening` / `ED` / `Ending` 标题，将有效范围接入现有媒体版本绑定的时间轴。章节边界可直接利用，计算成本较低，也无需引入外部时间段服务。应保留人工标注的优先级，并校验区间时长、顺序和边界；普通剧情章节不能仅凭接近 90 秒的时长被当作片头片尾。

没有章节的文件可进一步考虑后台 Chromaprint 分析，按同季、同字幕组或发行版本比较重复音频，按物理文件版本缓存结果。更换主题曲、特别篇、正片重复配乐，以及片尾后剧情都可能影响匹配，需要区分识别结果与人工修订。AniSkip 可以作为可选补充，但还需要作品标识映射、数据覆盖与不同发行版本时间偏移的处理。以上为后续方案，本次变更仅调整播放偏好和默认语言选择。
